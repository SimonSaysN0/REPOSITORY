ABOUT THIS MVP

How recommendations work

This prototype extracts product attributes, ranks records by keyword overlap, and displays relationships supplied in the dataset. It does not yet use semantic AI retrieval.

  1. Describe a product or paste tender text.
  2. Review extracted requirements.
  3. Inspect ranked candidates, source links, and recorded relationships.

Before real procurement use, load verified BIS metadata and references, add authoritative version and QCO sources, and have domain experts validate results. This is not official standards advice.
